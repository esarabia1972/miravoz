Conectar con MiraVoz

Revisando la sesión…

Una aplicación quiere acceder a tu cuenta registrada de MiraVoz para:

  • Ver, crear y modificar tus tableros (antes de cada cambio se guarda una versión para poder deshacerlo).
  • Ver tus usuarios, crear usuarios y asignarles tableros o actualizar sus copias.
  • Generar códigos para vincular tablets, cuando se los pidas.
  • Buscar pictogramas de ARASAAC.

No puede borrar usuarios ni desvincular tablets. Los cambios que afectan lo que ve un usuario se confirman antes. Podés quitar el acceso cuando quieras desde la aplicación que lo pidió.
